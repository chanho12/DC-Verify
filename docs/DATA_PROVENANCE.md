기존 원문 PDF·HTML, 이미지 렌더링, OCR 원문, 모델 응답, 실행별 절대 경로·원본 인용이 있는 결과, 환경 파일, 캐시·ZIP 리포트는 복사하지 않았다. 공개 목록은 상대 경로와 공개 URL·해시 등 출처 메타데이터만 포함한다. 제외 상세 경로는 배포 폴더 밖 repository_preparation/excluded_files.json에 있다. 상대 경로는 출처 기록이며 이 배포 폴더에 원문이 있다는 의미가 아니다.

canonical_claim_index는 Claim Key·문서 ID·페이지·원문 해시·검증 상태만 연결한다. Claim 수치·인용문·API 응답은 공개 목록에 포함하지 않았다. 새로운 합성 fixture는 명시적으로 SYNTHETIC_TEST_DATA이며 실제 기업의 자료나 실제 API 실행 결과가 아니다.
