# 미구현·제한 및 공개 차단 조건

| 기능/조건 | 상태 | 처리 |
|---|---|---|
| Resident DB·Seed 승인 등록·작업 간 인덱스 | MISSING | 이번에 구축하지 않음 |
| Controller의 Resident Local Retrieval 실행 | MISSING | SEARCH_LOCAL 계획/검사만 구현 |
| 전체 Agent 자동 End-to-End·Observe/Act Loop | PARTIAL | 실제 단일 단계 CLI만 제공 |
| SEC/OpenDART 전용 API 어댑터 | MISSING | 등록 후보만 존재 |
| Python Tavily Live 검증 | IMPLEMENTED_NOT_TESTED_LIVE | 기존 모의 transport/키 오류 테스트만 재사용 |
| 원문 포함 전체 사례 재현 | NOT_DISTRIBUTED | 원문·API 응답·계보 자료 재배포 권한 미확인 |
| 과거 절대 경로 기반 실행의 이동/이식 | MISSING | 입력 계보를 보존한 새 실행 또는 별도 마이그레이션 필요 |
| 실제 API 생성·OCR·검색 재실행 | NOT_PERFORMED_THIS_TASK | 이번 작업 지시상 금지 |
| 신규 환경의 온라인 의존성 다운로드 설치 | NOT_TESTED | 로컬 의존성으로 오프라인 wheel 설치만 검증 |
| 코드 공개 라이선스 선택 | UNDECIDED | 임의 LICENSE 파일/배포 권리 선언 없음 |
| 수집·사용자 원문 재배포 권한 | UNCONFIRMED | 원문을 제외; 공개 URL·해시 등 출처 메타데이터만 유지 |

따라서 로컬 업로드 준비 폴더는 제공하지만 Production 완성·투자 목표 달성·모든 End-to-End 재현·법적 재배포 권리까지 완료됐다고 주장하지 않는다. 실제 Git Commit·Push·원격 저장소 생성은 수행하지 않았다. 기존 사용자 검토 결과는 DEFER/INCOMPLETE이며 미확인 수치를 새 사실로 확정하지 않는다.
